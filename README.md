# MODULOR — website

Deze map is de volledige website. Elke wijziging die je naar de `main`-branch pusht,
staat binnen een paar minuten live via GitHub Pages.

- Pagina's: de `.html`-bestanden in deze map (`index.html` = home).
- Navigatie, achtergrond en poppetjes: `Navbar.dc.html` (geldt voor alle pagina's).
- Afbeeldingen en video: map `assets/`.
- `CNAME` bevat het domein, niet verwijderen.
- `.nojekyll` zorgt dat GitHub de bestanden ongewijzigd online zet, niet verwijderen.
